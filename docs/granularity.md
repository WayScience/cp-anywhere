# Granularity

`MeasureGranularity` is available for 2D images, in native Python and
WASM. It uses the pinned CellProfiler 4.2.8 reference, with scipy 1.9.3
and scikit-image 0.21.0.

```python
from cp_anywhere import measure_granularity

result = measure_granularity(
    dna_image,
    objects={"Cells": cell_labels},
    subsample_size=0.25,  # CellProfiler's own defaults
    image_sample_size=0.25,
    element_size=10,
    granular_spectrum_length=16,
)
result.image[0]  # GS1, the image-level granularity spectrum
result.objects["Cells"][0]  # GS1, one value per Cells object
```

`measure_granularity` is a standalone function, separate from the
unified `measure()` family dispatch: CellProfiler's own module measures
one image at a time, with its own subsampling/structuring-element
settings, and its result shape (per-scale spectra, not a flat feature
table) does not fit the shared `measure()` contract.

## Algorithm

For each image: optionally downsample for the main granularity
computation (`subsample_size`) and separately for background removal
(`image_sample_size`), using CellProfiler's own mix of bilinear
(order 1) pixel resampling and cubic B-spline (order 3) mask
resampling. Subtract a grayscale-opened background (erosion then
dilation with a disk structuring element of `element_size` radius),
then repeatedly erode with a radius-1 disk and reconstruct by
dilation, recording the percent change in masked mean brightness at
each of `granular_spectrum_length` scales.

Per-object spectra use the same per-scale reconstructed image, rescaled
back to full resolution, averaged over each object's unmasked pixels at
full resolution -- not the (possibly subsampled) working image directly.

An object with zero pixels under the mask reports `NaN` at every scale,
matching real CellProfiler: its own baseline mean is already `NaN`,
and `NaN` never recovers through the per-scale subtraction.

## Limits

- 2D only. Real CellProfiler's own module divides by
  `orig_shape[dimension] - 1` while rescaling its working image back to
  full resolution, and raises `ZeroDivisionError`, unconditionally, for
  any image with a 1-row or 1-column dimension -- confirmed live against
  the pinned reference. `measure_granularity` raises a clear `ValueError`
  for that case instead of silently producing 0/NaN; there is no real
  oracle value to match for it.
- `image` must already be at the same precision real CellProfiler would
  have measured. `Image(..., convert=True)` rescales integer dtypes by
  their dtype's max value (`identify_primary_objects` reproduces this
  automatically for segmentation inputs, but `measure_granularity` does
  not -- intensity measurements expect already-scaled float input, the
  same contract `measure()`'s other intensity families use) and always
  downcasts through `float32` even for float64 input. The second effect
  is usually negligible (~1e-7 relative) but is a real precision
  difference, not a cp-anywhere rounding bug, when reproducing an exact
  oracle run numerically.
- The `.cppipe` importer accepts revision 4 (7 settings: images, "measure
  within objects?", objects, both subsampling factors, element size,
  spectrum length). Every listed image is measured independently and
  merged into the same `MeasurementResult`, matching real CellProfiler's
  `Granularity_<scale>_<image name>` feature-naming convention.

## Verification

Real reference fixtures cover CellProfiler's own defaults, full
resolution (no subsampling), uneven subsample/background factors,
partial and fully-empty masks, zero/constant/negative images, and
multiple simultaneous object sets -- 12 cases total, generated by
`scripts/reference/generate_granularity.py` against a live pinned
CellProfiler run. A separate real two-image, two-object-set `.cppipe`
pipeline (`scripts/cppipe/generate_granularity_pipeline.py`) exercises
the full `IdentifyPrimaryObjects` -> `IdentifySecondaryObjects` ->
`IdentifyTertiaryObjects` -> `MeasureGranularity` chain end to end.

The browser check runs `measureGranularityJson` in real Playwright
Chromium, not a simulated WASM runtime.

To regenerate and check the reference data:

```sh
PYTHONPATH=/path/to/pinned/CellProfiler /path/to/reference/python \
  scripts/reference/generate_granularity.py
PYTHONPATH=/path/to/pinned/CellProfiler /path/to/reference/python \
  scripts/cppipe/generate_granularity_pipeline.py
uv run --frozen pytest tests/test_granularity.py tests/cppipe/test_granularity_pipeline.py
python scripts/wasm/build_package.py
uv run --frozen python scripts/parity/compare_wasm_granularity.py
```

The browser check requires the browser example's existing Node
dependencies and Playwright Chromium installation.

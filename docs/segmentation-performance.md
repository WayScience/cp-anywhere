# Segmentation performance: native Rust vs real CellProfiler

Methodology matches `docs/native.md`'s measurement benchmarks: 3
warmup runs, 20 timed runs, median wall-clock `time.perf_counter_ns`
per call, on real microscopy fixtures (`fixtures/segmentation/`,
generated by `scripts/segmentation/generate_reference.py`). Both sides
run `IdentifyPrimaryObjects` with identical settings (Global two-class
Otsu, no declumping/watershed/hole-filling/border-exclusion -- see
`spec/segmentation-modules.md`).

Reproduce with:

```sh
uv run python benchmarks/benchmark_segmentation_native.py
PYTHONPATH=<cellprofiler checkout> \
  <reference venv>/bin/python benchmarks/benchmark_segmentation_cellprofiler.py
```

(`benchmarks/benchmark_segmentation_cellprofiler.py` runs the real,
pinned CellProfiler 4.2.8 -- see `reference/install.sh` for setting up
that separate environment -- not a reimplementation.)

## Results

| Fixture                  | Shape   | Objects | cp_anywhere (median) | CellProfiler (median) | Speedup |
| ------------------------ | ------- | ------- | -------------------- | --------------------- | ------- |
| `real_cell_cc0_dna_otsu` | 96x96   | 10      | 0.149 ms             | 7.214 ms              | 48.3x   |
| `real_bbbc007_dna_otsu`  | 128x128 | 8       | 0.105 ms             | 6.483 ms              | 62.0x   |

Full raw samples: `benchmarks/reports/segmentation-native-baseline.json`,
`benchmarks/reports/segmentation-cellprofiler-baseline.json`,
`benchmarks/reports/segmentation-native-vs-cellprofiler.json`.

## Limitations

- Fixtures are small (96x96/128x128) real-microscopy crops, not
  whole-slide images; absolute timings and the speedup ratio will
  differ at larger scale (connected-component labeling is roughly
  linear in pixel count for both implementations, so the ratio should
  stay in the same range, but this has not been measured directly).
- CellProfiler's `IdentifyPrimaryObjects.run()` includes its own
  Settings validation and measurement bookkeeping overhead on every
  call, not just the segmentation algorithm itself; this is still the
  real, representative per-call cost a CellProfiler pipeline pays.
- Timing is a comparison baseline, not evidence of output
  equivalence -- see `tests/segmentation/test_reference_alignment.py`
  and `spec/segmentation-modules.md` for the actual parity claims.

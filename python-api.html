cp_anywhere.io#

The simplest entry point for files on disk: cp_anywhere.io.measure_files() accepts TIFF/OME-TIFF, PNG, or saved NumPy array paths (or already-loaded arrays) directly and returns a tidy pandas.DataFrame, instead of requiring images to be pre-converted to NumPy arrays first.

Load images and label arrays directly from common file formats.

This is the simple entry point for users with ordinary microscopy files (TIFF/OME-TIFF, PNG, or saved NumPy arrays) who do not want to pre-convert anything by hand. measure_files wraps cp_anywhere.api.measure() and returns a tidy pandas.DataFrame instead of a MeasurementResult.

cp_anywhere.segment#

Object segmentation (cp_anywhere.identify_primary_objects()), implemented against CellProfiler’s IdentifyPrimaryObjects module as the compatibility oracle – see segmentation coverage for the declared scope and verification status.

Object segmentation, implemented against CellProfiler 4.2.8’s IdentifyPrimaryObjects module (and the shared Threshold module it uses) as the compatibility oracle.

Declared scope: every global and adaptive threshold operation (Manual, Otsu two/three-class, Li, Robust Background, Sauvola), log transform, threshold smoothing, declumping/watershed (Intensity/Shape/Propagate), hole filling (including nested-object absorption), border exclusion, and size/count filtering – see spec/segmentation-modules.md for the exact settings mapping and the explicit remaining gaps (not silent approximations).

CellProfiler’s own Threshold module hard-bounds manual_threshold and threshold_range to [0, 1] and assumes images have been rescaled to that range (its default Image(..., convert=True) divides integer-dtype pixels by their dtype’s max value; float-dtype pixels are never rescaled). identify_primary_objects reproduces that default behavior automatically (rescale=True) so passing a raw uint8/ uint16 image works exactly like a default CellProfiler pipeline, with no manual conversion needed.

The result chains directly into cp_anywhere.measure():

seg = cp_anywhere.identify_primary_objects(dna_image, threshold="otsu")
result = cp_anywhere.measure({"DNA": dna_image}, {"Cells": seg.labels})

src.cp_anywhere.segment.identify_primary_objects(image: object, *, mask: object | None = None, threshold: str | float | int = 'otsu', rescale: bool = True, threshold_correction_factor: float = 1.0, threshold_range: tuple[float, float] | None = None, exclude_size: bool = False, min_diameter: float = _MIN_DIAMETER_DEFAULT, max_diameter: float = _MAX_DIAMETER_DEFAULT, exclude_border_objects: bool = False, maximum_object_count: int | None = None, fill_holes: str = 'never', threshold_smoothing_scale: float = 0.0, assign_middle_to_foreground: bool = True, robust_background_lower_outlier_fraction: float = 0.05, robust_background_upper_outlier_fraction: float = 0.05, robust_background_averaging_method: str = 'mean', robust_background_variance_method: str = 'sd', robust_background_number_of_deviations: float = 2.0, log_transform: bool = False, threshold_scope: str = 'global', adaptive_window_size: int = 50, unclump_method: str = 'none', watershed_method: str = 'none', smoothing_filter_size: float | None = None, maxima_suppression_size: float | None = None, low_resolution_maxima: bool = False) → SegmentationResult[source]#

Segment one 2D grayscale image into labeled primary objects.

rescale (default True) matches CellProfiler’s own default image loading: integer-dtype images (uint8/uint16/uint32) are divided by their dtype’s max value before thresholding, exactly like CellProfiler’s Image(..., convert=True); float-dtype images are never rescaled (also matching CellProfiler). Set rescale=False to operate on raw pixel values directly instead (matching this project’s measurement API’s own convert=False convention).

threshold is "otsu" (two-class, global, 256-bin histogram – CellProfiler’s default algorithm for any already-float pixel data, which is what every image becomes after rescaling), "otsu_integer" (exact one-bin-per-value histogram; only valid with rescale=False on an integer-dtype image – matches CellProfiler’s Otsu only if CellProfiler would also have skipped rescaling), "otsu_three_class" (a 128-bin, 3-class histogram split; assign_middle_to_foreground picks the lower split, i.e. the middle class counts as foreground, when True (default), or the upper split when False, matching CellProfiler’s "Foreground"/"Background" setting), "li" (Li’s iterative Minimum Cross-Entropy threshold, matching skimage.filters.threshold_li with CellProfiler’s own tolerance formula), "robust_background" (a trimmed mean/median/mode – robust_background_averaging_method – plus a multiple – robust_background_number_of_deviations – of the standard deviation or MAD – robust_background_variance_method – computed after discarding robust_background_lower_outlier_fraction/ robust_background_upper_outlier_fraction of the lowest/highest pixels; matches Threshold.get_threshold_robust_background exactly, including its quirk where a zero lower-fraction also disables the upper trim), "sauvola" (a local mean/standard- deviation formula over a sliding window, only valid with threshold_scope="adaptive" – matches skimage.filters.threshold_sauvola; CellProfiler’s own global_operation Choice does not even include Sauvola, so this raises if combined with threshold_scope="global"), or a numeric manual threshold value, interpreted in the same units as the (possibly rescaled) pixels actually compared against it.

threshold_scope (default "global") matches Threshold.threshold_scope: "global" applies one scalar threshold to the whole image; "adaptive" instead computes a per-pixel threshold map by splitting the image into adaptive_window_size-sized blocks (computing a block threshold with the same algorithm named by threshold – or a direct sliding-window Sauvola computation, which has no block/spline step), blending the block grid across the image with a tensor-product B-spline (matching scipy.interpolate.RectBivariateSpline), and finally clamping the result to [0.7, 1.5] * guide_threshold (the ordinary global threshold, used only as a bound; for "sauvola" this guide is computed via "li", matching CellProfiler’s own shared branch). threshold_map (a same-shape array) and guide_threshold on the returned SegmentationResult are None unless threshold_scope="adaptive"; "manual" and "otsu_integer" are not supported with adaptive scope (CellProfiler’s own local_operation Choice does not include either).

log_transform (default False) matches CellProfiler’s Threshold.log_transform setting, meaningful only when threshold is "otsu", "otsu_three_class", or "li" (CellProfiler itself only exposes this setting for those global operations; it is silently ignored for "otsu_integer", "robust_background", and numeric manual thresholds, matching CellProfiler’s own behavior). When enabled, the threshold is computed on a log-transformed, [0, 1]-rescaled copy of the entire image (not just the masked subset) and mapped back before threshold_correction_factor/clamping, exactly matching centrosome.threshold.log_transform/inverse_log_transform.

exclude_size/min_diameter/max_diameter match CellProfiler’s IdentifyPrimaryObjects size filter: objects whose pixel area falls outside pi * diameter^2 / 4 for the given diameter bounds are removed.

exclude_border_objects (IdentifyPrimaryObjects.exclude_border_objects) removes any object touching the image border (or, if mask is given and nothing touches the image border directly, any object touching the mask’s own border instead).

maximum_object_count (IdentifyPrimaryObjects.maximum_object_count, only enforced when not None) erases every object if the final count exceeds this value, matching CellProfiler’s LIMIT_ERASE.

fill_holes (IdentifyPrimaryObjects.fill_holes) is one of "never" (default), "after_declump_only" (fills background holes enclosed by a single object, after border/size filtering), or "after_thresholding_and_declump" (also fills holes in the binary foreground mask before labeling, limited to area < max_diameter^2). A background region bordered by two or more different objects (not fully enclosed by one) is left unfilled, matching centrosome.cpmorphology.fill_labeled_holes exactly, including its handling of a small object fully nested inside a larger one (absorbed into the enclosing label) and multi-level nested holes.

threshold_smoothing_scale (Threshold.threshold_smoothing_scale, default 0.0 – no smoothing) blurs the image used for the foreground/background comparison (not the value used to compute the threshold, which is always the unsmoothed image) with a Gaussian of sigma = threshold_smoothing_scale / 0.6744 / 2.0, matching CellProfiler’s apply_threshold exactly, including its mask-bleed-over correction near the image border.

unclump_method/watershed_method (IdentifyPrimaryObjects.unclump_method/watershed_method) separate touching objects after initial labeling and before border/size filtering – matching separate_neighboring_objects’s exact position in CellProfiler’s pipeline. unclump_method is "none" (default; no separation), "intensity" (find local intensity maxima in a Gaussian-smoothed copy of the image), or "shape" (find local maxima of the Euclidean distance transform of the foreground, jittered with CellProfiler’s own fixed-seed(0) legacy-RNG noise to break exact ties). watershed_method is "none" (default), "intensity" (watershed on 1 - image), "shape" (watershed on the negated distance transform – reuses the same jittered transform computed above when unclump_method="shape" too, matching CellProfiler’s own if distance_transformed_image is None check), or "propagate" (centrosome.propagate.propagate, a distinct non-watershed algorithm; ignores both image and distance-transform inputs, geometric distance only). Both must be set to something other than "none" for separation to actually run, matching CellProfiler’s own UN_NONE/WA_NONE no-op check.

smoothing_filter_size/maxima_suppression_size override CellProfiler’s own automatic formulas (2.35 * min_diameter / 3.5 and min_diameter / 1.5 respectively) when given explicitly, matching automatic_smoothing/automatic_suppression set to False with an explicit Float Setting value. low_resolution_maxima (IdentifyPrimaryObjects.low_res_maxima) only takes effect when min_diameter > 10.0 (CellProfiler’s own gate); when both are true, maxima are found on a downsampled copy of the image for speed – not yet implemented, raises if triggered.

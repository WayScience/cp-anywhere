cp_anywhere.io#

The simplest entry point for files on disk: cp_anywhere.io.measure_files() accepts TIFF/OME-TIFF, PNG, or saved NumPy array paths (or already-loaded arrays) directly and returns a tidy pandas.DataFrame, instead of requiring images to be pre-converted to NumPy arrays first.

Load images and label arrays directly from common file formats.

This is the simple entry point for users with ordinary microscopy files (TIFF/OME-TIFF, PNG, or saved NumPy arrays) who do not want to pre-convert anything by hand. measure_files wraps cp_anywhere.api.measure() and returns a tidy pandas.DataFrame instead of a MeasurementResult.

src.cp_anywhere.io.load_array(source: object) → ndarray[source]#

Load one image or label array from a file path, or pass an array through.

Dispatches on file suffix: .npy via numpy.load(), .tif/ .tiff via tifffile, and .png/.jpg/.jpeg/.bmp/ .gif via Pillow. An already-loaded numpy.ndarray is returned unchanged.

src.cp_anywhere.io.measure_files(images: Mapping[str, object] | str | Path, objects: Mapping[str, object] | str | Path, *, mask: object | None = None, image_id: str = 'Image', families: Sequence[str] | None = None) → pd.DataFrame[source]#

Measure images and objects given as file paths (or arrays), as a table.

images/objects may each be a single path/array (named “DNA” and “Cells” respectively) or a mapping of channel/object-set name to path/array, exactly like cp_anywhere.api.measure() but accepting file paths for any supported format (see load_array()) in addition to already-loaded arrays. Returns one row per object per feature column (see cp_anywhere.api.MeasurementResult.rows()).
